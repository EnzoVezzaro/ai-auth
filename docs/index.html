AI Auth home

Local setup

Start the current local collaboration service with Node.js 22 or newer. This is an early single-site MVP; external authentication, MCP, native WebMCP, and real autonomous-agent tests are not included. 

npm ci
npm run dev

API: http://127.0.0.1:3333. Dashboard: /dashboard. SQLite: ./data/ai-auth.sqlite.

Register a local agent

curl -X POST http://127.0.0.1:3333/v1/agents/register \
  -H 'content-type: application/json' \
  -d '{"name":"Writer","category":"autonomous_agent"}'

Registration is open for local development. Save the one-time token. Do not expose the service to an untrusted network.
