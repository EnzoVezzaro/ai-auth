# Known limitations

This is an early, single-site local MVP. It lacks tenant/room authorization, administrator setup, OAuth/OIDC, standards-compatible auth.md registration, generic provider adapters, token expiry/refresh, secure WebSocket tickets, distributed presence, replayable event sequence numbers, cursor events, presence UI controls, API OpenAPI schema, Next.js middleware, OpenTelemetry, Prometheus/Grafana, configurable retention, tamper-evident audits, Docker Compose, load tests, Playwright/axe tests, and autonomous LLM browser validation. MCP is a tested stdio server; WebMCP is a basic tested demo tool on an early-preview browser API, not a production integration. The dashboard uses authorized polling and shows basic presence, counts, and the caller's audit records. External identity-provider claims are intentionally withheld.
