Source: the dated notes already recorded in [Agents and MCP](agents.md), the transport contract in [MCP command](mcp.md), the lifecycle rules in [Session and connection lifecycle](lifecycle.md), plus a live verification executed from the terminal of this OpenCode harness (see "Live verification in this environment" below). No CI run, desktop chat-app session or interactive harness MCP session was executed; the live checks are terminal-run repository commands and tests, one of which drives a headless Chromium page.

## Scope and honesty rules

A static GitHub Pages page cannot install, start or configure a local process by itself. AI Auth has no trusted local installer component that performs an install and confirms it, so **automatic local install does not exist and is not promised**. Every supported path below still requires a real local action by the person and an explicit verification step.

This register reports two kinds of evidence: dated notes in `docs/agents.md`, and the live terminal checks recorded below. "Verified" for a dated note means the note describes that specific outcome; it does not mean current behavior, a completed CI run, or a reproducible session on a current client version. "Verified live" means a command was executed in this environment on the recorded date with the recorded output; it does not mean an interactive session of that client or a call that reached a peer. Where the underlying note omits the OS or client version, this matrix records **NO REGISTRADO** instead of guessing.

No version number is introduced by this register. Product and package version labels come from each package's `package.json`, with the root `package.json` as the single release source; version strings in nontechnical UI are generated from that source or omitted. See [P2-16](#p2-16-version-source-of-truth) below.

### Cómo leer el resultado

- **VERIFICADO (parcial):** la nota fechada describe el desenlace indicado, pero no registra OS, versión del cliente ni una sesión reproducible hoy. No equivale a compatibilidad certificada.
- **PARCIAL:** se observó parte del camino (por ejemplo, registro de herramientas o sala compartida) sin la prueba completa de llamada, prueba firmada o canal autenticado para la identidad esperada.
- **NO VERIFICADO:** no hay nota fechada en el repositorio que respalde el desenlace. Registrar herramientas no es prueba de una llamada completada.
- **SIN SOPORTE DEMOSTRADO:** no existe evidencia de un adaptador local para esa variante. Un cliente puramente de navegador no puede instalar un proceso local.
- **VERIFICADO EN VIVO (automatizado):** un comando del repositorio se ejecutó en este entorno en la fecha registrada y produjo la salida registrada. No equivale a una sesión interactiva del cliente ni a una llamada que haya llegado a un par.

Desktop y web se mantienen como filas independientes: un resultado en ChatGPT desktop no dice nada sobre ChatGPT web. Una comprobación automatizada por terminal tampoco dice nada sobre una sesión interactiva de OpenCode, Claude Code, Codex o ChatGPT.

The UI should choose a known path from this registry, ask for local permission, and otherwise give short copyable steps plus an explicit proof action. Verification is mandatory whatever the adapter.

## What a result does and does not prove

- The dated notes record self-reported runtime and environment metadata. They do not prove a particular OS, client version, model, vendor or physical machine.
- A note about a WebRTC tool call proves a peer received traffic on that session; it does not by itself prove expected-wallet/instance binding, nonce freshness or a current authorization. Those checks are specified in [Connect Agent E2E acceptance](CONNECT_AGENT_E2E_ACCEPTANCE.md).
- `connected` is true only while a real authenticated data channel is open for the expected identity and session; a saved key, a discovered tool catalog or a reachable MCP endpoint is not a connection ([lifecycle](lifecycle.md)).
- There is no TURN server. A restrictive NAT can block the direct path; report that honestly instead of claiming universal connectivity.
- Verify each live session with `ai_auth_status`. Do not treat this register as a substitute for that check.

## Evidence required to upgrade a row

To move a cell from NO VERIFICADO or PARCIAL to VERIFICADO, record: OS and client version, the observation date, the exact command and transport, a redacted `ai_auth_status` result showing connection state and effective granted scopes, and a sanitized screenshot or log. Test ChatGPT web independently from ChatGPT desktop. Do not call a listed MCP server proof of a completed tool call.
