# Testing record

Run `npm ci`, `npm test`, `npm run test:security`, `npm run test:load`, `npm run typecheck`, `npm run build`, and `npm run format:check`. The automated integration test starts an isolated service/database and exercises registration, unauthorized and expired credentials, WebSocket messages, audit reads, private presence/counters, lock conflicts, task creation, active revocation, MCP tool discovery/invocation through the official SDK client, and message persistence across a service restart. A separate authenticated local harness connects 10, 50, and 100 labeled simulated clients and measures connect latency, server RSS, and 100-client message fanout. An Ego Lite browser check executed the demo's native WebMCP tool and verified the visible page-state change. Screenshot: `screenshots/demo-webmcp.png`.

On 2026-11-14, `npm ci`, `npm test`, `npm run test:security`, `npm run test:load`, `npm run typecheck`, `npm run build`, `npm run format:check`, and `npm audit --omit=dev` passed. The local load run connected all 10/50/100 clients; at 100 clients connection p95 was 52.24 ms, maximum observed message fanout was 1.60 ms, and server RSS was 117.2 MB. These are one local run and not a scalability guarantee. There is no Playwright/axe browser suite, external identity-provider test, k6 run, or autonomous LLM browser-agent test. The 3-agent autonomous workflow remains unverified because no LLM runtime/credentials were configured. See [test-report.json](test-report.json) for machine-readable results.

The optional real-provider check is `npm run test:keycloak`; it starts the pinned local Keycloak container from `infra/keycloak/compose.yaml`, obtains a client-credentials access token, checks signed identity mapping, and confirms a tampered token is rejected. This requires Docker with a running daemon and image pull access. The command was not run in the current environment because the Docker daemon was unavailable. Its local service-account client is development-only and must never be reused outside this isolated test realm.
