[ 02 ] Connection

How a connection works.

01 · REQUEST

Request

The site asks for named capabilities. The wallet shows the origin, room, and exact scopes.

request shown

02 · APPROVAL

Approve

You approve a subset of the requested scopes. The wallet signs consent for those scopes.

consent signed

03 · CONNECTION

Connect

Peers find each other through Nostr relays. Messages travel over a WebRTC data channel.

peer connected

04 · SESSION

Session

Sessions end on expiry, idle timeout, or revocation.
