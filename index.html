Agent identity for the open web

Your agents. Their identities. Anywhere.

Give your AI agents a wallet they can carry across the web. Connect to websites, approve what they can do, and let them work alongside people and other agents.

04 / The open web

One wallet. Many direct connections.

Public Nostr relays help peers find each other. The collaboration itself travels over direct WebRTC data channels, with every event signed by the wallet that sent it.

Scoped permissions
Each grant names exact capabilities for one origin. A renewal can narrow the scopes but cannot add capabilities.
Peer discovery
Relays carry signaling and room topics. They never receive the signed collaboration events.
Direct WebRTC
Peers exchange messages, presence, and tool results in a data channel between their own machines.
Signed events
Receivers check the signature, session, scope, and replay state before an event is used.
Protocol facts
Identity key ECDSA P-256 in browser storage or an encrypted file keystore
Discovery Public Nostr relays carry signaling only
Collaboration Signed events over direct WebRTC
Session grant Exact scopes for one origin, owner sets the length

05 / The SDK

A few calls to connect a site.

The browser package handles the wallet dialog, consent, and the peer room. The agent package keeps a key in an encrypted local keystore. The MCP package gives local runtimes a way to use it. 

import { connectAIAuthModal, mountAIAuthCollaboration }
  from "@enzovezzaro/ai-auth-wallet";

const connection = await connectAIAuthModal({
  walletUrl: "https://your-wallet-host/wallet/",
  capabilities: ["presence.read", "tools.invoke"],
  room: "project-room",
});

const removeCursors = mountAIAuthCollaboration(connection);
import { createFileKeystore, createAgentRuntime }
  from "@enzovezzaro/ai-auth-agent";

const keystore = createFileKeystore({ dir: "./.ai-auth/agent" });
await keystore.create();
await keystore.unlock();

const runtime = createAgentRuntime({
  keystore,
  origin: "https://workspace.example",
  capabilities: ["presence.read", "tools.invoke"],
});
await runtime.join("project-room");
# local stdio server for coding agents
npx -y @enzovezzaro/ai-auth-mcp init
npx -y @enzovezzaro/ai-auth-mcp serve \
  --connect https://workspace.example \
  --room project-room \
  --caps presence.read,tools.invoke \
  --auto-join
walletUrl points to the host where you serve the wallet. javascript

06 / Open architecture

Self-custodied by design.

Your key lives in your browser's origin-scoped storage or in an encrypted file on your machine. AI Auth runs no authentication service, database, or collaboration backend. The code is MIT licensed.

Build with AI Auth ↗ Open the wallet

Relays used for discovery are public infrastructure, not an AI Auth service. There is no global revocation switch.
